# 秋日公园 UI 焕新 + 音乐播放体验设计

日期：2026-08-02

## 1. 背景与目标

用户反馈两个问题：

1. 背景音乐「播放太快」——经排查，音频文件本身是正常的 44.1kHz MP3，问题出在播放体验：自动播放太突然、无音量控制、无曲目提示、切歌无过渡。
2. 界面「太丑、太单调、没有动态效果」——现有玻璃拟态浅色主题缺乏层次与生命力。

目标：在不动数据结构和后端 API 的前提下，把访客可见的界面统一改成「简约高级」风格（用户已确认的方向 B），并补齐音乐播放器体验与三类动效（环境、交互、滚动/过渡）。

## 2. 已确认的决策

| 议题 | 决策 |
|---|---|
| 音乐 | B：保留现有曲目，优化播放体验（音量、渐入渐出、播放/暂停、曲目名） |
| 视觉方向 | B：简约高级（留白、衬线标题、细线稿插画、克制大地色） |
| 动效 | C：环境动效 + 交互反馈 + 滚动/过渡动画全都要 |
| 改造范围 | B：首页 + 照片墙 + 留言墙 + 登录注册全站统一；管理后台保持简洁实用，只继承基础样式 |

## 3. 视觉设计令牌（globals.css）

统一替换现有 `glass` 玻璃拟态浅色体系：

| 令牌 | 值 | 用途 |
|---|---|---|
| 背景 `--bg` | `#f7f6f2` | 页面底色（暖白） |
| 场景渐变 | `#f3efe6 → #f7f4ec → #eee7da` | 主页天空/画布 |
| 表面 `--surface` | `#ffffff` | 卡片、弹窗 |
| 墨色 `--ink` | `#2c2822` | 主文字、实心按钮 |
| 次级文字 | `#6b645a` / `#8b8579` | 说明文字 |
| 弱文字 | `#b3aca0` | 时间戳、小标签 |
| 强调色 `--accent` | `#b56a4c`（陶土红） | 高亮词、进度条、主强调 |
| 次强调 `--accent-2` | `#c98a4b`（琥珀金） | 落叶、点缀 |
| 分隔线 | `rgba(60,52,40,.08~.14)` | 细边框、分隔线 |
| 圆角 | 卡片 12px / 弹窗 16px / 胶囊 999px / 场景 20px | 统一层级 |
| 阴影 | `0 6px 18px rgba(50,40,25,.05)` | 极轻的悬浮感 |

字体：标题与正文使用 `Georgia, 'Noto Serif SC', 'Songti SC', serif`；小标签（kicker/栏目名）使用衬线体 + `letter-spacing .3em` 大写感。**不引入外部字体文件**（国内加载 Google Fonts 不可靠）。

组件样式调整：
- `.glass-btn` / `.glass` / `.glass-strong` / `.glass-input` 改为白底细边框的简约样式，保留类名以免大范围改 JSX。
- `.btn-primary` 改为墨色实心胶囊；`.btn-ghost` 改为细边框幽灵按钮。
- 新增 `.card-hover`（悬浮上浮 + 阴影加深）、`.chip`（胶囊信息条）、`.hairline`（细分隔线）等工具类。

## 4. 首页（app/park/page.tsx + ParkScene）

- 顶部右侧控件收敛为三个胶囊：天气（今日晴 · 22°）、音乐播放器、登录/用户菜单。
- Hero 区改为：`AUTUMN PARK · 四季流转` 小标签 + 大标题「在秋天，慢慢散步。」（`em` 强调色）+ 说明文字 + 两个按钮（实心「进入公园 →」/ 幽灵「浏览相册」）。
- ParkScene 重画：暖白渐变天空、细线稿树木（SVG，陶土/琥珀点缀叶）、柔和日光（呼吸动画）、低透明度云朵（缓慢漂移）、地平线细线。保留四季/天气/昼夜叠层逻辑，但把颜色换成新令牌。
- 移除 `misty-trees.jpg` 纹理层（与简约方向冲突），以细线稿插画替代。
- 滚动提示改为细线 + 「向下漫步」小字。

- 个人角落（CornerView / PhotoWall / PhotoModal）：只继承全局样式变化，不做单独重排。

## 6. 登录注册与用户菜单

- LoginModal：白底圆角卡片、细分隔线 Tab（登录/注册）、衬线标题「进入公园」、墨色实心提交按钮；输入框统一 `#fbfaf7` 底 + 细边框。
- UserMenu：与顶部胶囊风格一致；管理按钮保留但弱化（文字按钮）。

## 7. 音乐播放器（components/park/AmbientSound.tsx）

保留现有曲目与天气音效引擎，重做 MusicPlayer 交互：

- **曲目名**：新增 `url → 显示名` 映射（Canon in D、Air in G Minor、Gymnopédie No.1、Liebestraum No.3、Adagio in G Minor、Pavane、Cello Suite No.1）。
- **播放/暂停**：点击切换，按钮图标同步；暂停时保留进度，恢复时从原位置继续。
- **下一首/上一首**：在现有洗牌逻辑上补充显式切换；切歌时先淡出再淡入。
- **音量滑块**：UI 提供 0~100 滑块，默认 0.3；调音量用 50ms 步进渐变，避免爆音。
- **渐入渐出**：播放/暂停/切歌统一 1.2s 音量渐变（`setInterval` 或 `requestAnimationFrame` 平滑调整 `audio.volume`）。
- **自动播放策略**：不再打开页面就响；首次用户交互（任意 click）后以 0 音量淡入启动（若用户此前未手动关过音乐）；开关状态记录在组件内存中。
- **UI**：音乐胶囊按钮显示 `♪ 曲目名`，点击展开小浮层（播放/暂停、上一首/下一首、音量、曲目名）；天气音效保留为独立小胶囊。

## 8. 动效设计

### 8.1 环境动效（常驻、低频）
- ParticleOverlay 调参：秋季落叶数量适中（≤24 片）、更慢的飘落；春季花瓣、冬季雪花、雨/雾沿用，颜色对齐新令牌。
- 日光呼吸（8s）、云朵漂移（20s）、树叶轻微摆动（CSS keyframes，新加）。
- 所有环境动画低频且透明，不抢内容。

### 8.2 交互动效
- 卡片 hover：`translateY(-3px)` + 阴影加深（0.2s）。
- 按钮按下：`scale(0.97)`（0.1s）。
- 照片卡片 hover：恢复水平（rotation 0）+ 轻微上浮。
- 导航/胶囊 hover：背景 `rgba(60,52,40,.04)`。

### 8.3 滚动与过渡（GSAP + ScrollTrigger）
- 入场：Hero 淡入上移（复用现有 GSAPAnimations，扩充元素选择器）。
- 滚动显现：相册区、留言区进入视口时 `opacity/y` 显现（`ScrollTrigger`，stagger 0.06s）。
- 视差：场景天空/树木/日光随滚动轻微位移（速度 0.2~0.4）。
- 弹窗：fade + scale（0.96→1）入场。
- 季节切换背景 crossfade 保留（现有 2s transition）。

### 8.4 无障碍与性能
- `prefers-reduced-motion: reduce` 时关闭环境粒子与滚动动画（CSS media query + JS 检测跳过 GSAP/粒子初始化）。
- 粒子总数上限保持现状（`getMaxParticles`），不增加 CPU 负担。
- 动效只作用于 transform/opacity，避免频繁重排。

## 9. 不改的东西（YAGNI）

- 不新增页面、不新增后端 API、不改数据库结构。
- 不重做管理后台（AdminPanel 仅随全局样式自然变化）。
- 不换/不下载音频文件（用户选择了保留曲目优化体验）。
- 不引入外部字体、不引入新的 UI 库（继续用 Tailwind + GSAP + framer-motion 现有依赖）。
- 不动已上线的性能缓存逻辑。

## 10. 验证方式

1. `npm run lint`：0 error。
2. `npm run build`：通过。
3. Playwright 回归：首页无 console 错误；Hero、相册、留言、音乐胶囊、登录弹窗正常渲染；移动端宽度（375px）无横向溢出。
4. 手动清单：播放/暂停、音量、切歌、淡入淡出；`prefers-reduced-motion` 下无环境粒子。
